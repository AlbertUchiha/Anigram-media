# Anigram-media
Create a production-ready mobile application called "Anigram".

Anigram is an all-in-one anime-themed super app combining:
- Social media (Instagram-like feed)
- Short videos (TikTok-like system)
- Real-time chat (Telegram-like messaging)
- Marketplace for anime products
- AI anime image generator

GOAL:
Build an extremely smooth, fast, and enjoyable user experience with a modern anime cyberpunk aesthetic.

---

CORE FEATURES:

1. AUTHENTICATION SYSTEM
- Phone number login with OTP verification
- Optional Google login
- Create user profile after first login
- Store user data in database
- Redirect to home feed after login
- Maximum 2-step login flow

2. USER PROFILE SYSTEM
- Profile photo
- Username
- Bio
- Followers / following system
- User posts and videos grid
- Edit profile functionality

3. HOME FEED (MAIN SCREEN)
- Scrollable feed of posts and short videos
- Each post contains image/video, username, caption
- Like, comment, share functionality
- Follow/unfollow users directly from feed
- Real-time updates
- Smooth infinite scroll

4. POSTING SYSTEM
- Upload images, videos, or text posts
- Add captions and hashtags
- Save posts to database
- Instant publish to feed

5. CHAT SYSTEM
- Real-time one-to-one messaging
- Chat list screen
- Message bubbles (sent/received)
- Image and text support

6. MARKETPLACE SYSTEM
- List anime-related products
- Seller profiles
- Product detail pages
- Buy / contact seller functionality
- Ratings and reviews

7. AI ANIME GENERATOR
- Text prompt input
- Generate anime-style images from prompt
- Save and share generated images

8. EXPLORE PAGE
- Trending posts and videos
- Hashtag-based discovery
- Search users and content

---

DESIGN REQUIREMENTS:

- Dark mode default
- Neon purple and blue cyberpunk anime theme
- Minimal and clean UI
- Rounded modern components
- Smooth animations and micro-interactions
- Highly intuitive navigation
- Instagram + TikTok + Telegram inspired layout

---

UX REQUIREMENTS:

- Maximum 2–3 taps to reach any feature
- Fast loading performance
- Lazy loading for feed and videos
- Smooth scrolling experience
- Haptic feedback for interactions
- Smart suggestions (hashtags, captions, users)
- Comfortable and addictive but non-overwhelming experience

---

PERFORMANCE:

- Optimized for low-end devices
- Efficient image/video loading
- Real-time database updates
- Scalable architecture

---

APP EXPERIENCE GOAL:

The app should feel like:
"Instagram + TikTok + Telegram + Marketplace + AI Anime Studio combined into one seamless anime universe app"
